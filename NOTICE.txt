This repository contains no Magpie backend application or plugin adapter.

The frontend directly reuses Magpie app.css, opencode.svg, HTML header/list/ledger structure and selected app.js DOM controls (including the model switch and effort slider/pointer/keyboard logic). library.css switch rules are retained. Unrelated pages and original Magpie/Wails runtime/API calls are removed; the UI calls the standalone OpenCode Proxy management API.
Source metadata and checksums: frontend/src/magpie/SOURCE.json. Refresh script: scripts/vendor-magpie.mjs. Original MIT notice retained.
The metric rules ledDecode/ledRowSpeed and flowMs derive from Magpie app.js, gateway/ttft.go, and usage/usage.go at the same source commit. All retain the original MIT notice.
