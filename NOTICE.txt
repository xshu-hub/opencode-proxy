This repository contains no Magpie backend application or plugin adapter.

The frontend is based on Magpie's index.html, app.js, i18n.js, caller-keys.js, app.css, library.css, supporting scripts and icons at https://github.com/yetone/magpie/tree/a75de4c21ac28be98af8334643077d8b0bf47df7. Original provider/model editor, gateway, connection examples, modal, picker, sidebar and key renderers are retained. Edits are in scripts/vendor-magpie.mjs and frontend/public/proxy-adapter.js. Unrelated views, including usage and request records, are removed after initialization; their module scripts are not loaded. No Magpie server or plugin is built or used.
Source metadata and original file checksums: frontend/public/SOURCE.json. Refresh script: scripts/vendor-magpie.mjs. Original MIT notice retained.
