# OpenCode 1 共享进程真实模型验证（2026-10-28）

本记录使用本机 **OpenCode 1.18.0**、Node.js 22.23.2 和真实已配置的
**`deepseek-flash`**。三种客户端协议都经代理和全局 OpenCode 推理，未使用模拟供应商，
未直连供应商，也未修改 OpenCode。用户限定模型后，后续全部推理只使用该模型。

测试读取本机代理配置并创建独立回环地址临时网关，启用 `workerSharing=true`，
保持默认不限并发。网关使用一次性访问 Key，认证仍走 `runtime.authenticate`；
供应商认证由全局 OpenCode 处理。本机配置及全局认证文件没有写入。
这不是对正在运行的用户网关或打包程序的测试。

## 结果

主回归 **16/16 通过**，补充隔离回归 **4/4 通过**；两次均包含连通性检查，
合计 **19 个不同场景**。原始报告只包含本次生成的测试内容和指标，位于系统临时目录：

- `opencode-proxy-shared-live-22RY9h/report.json`：主回归。
- `opencode-proxy-shared-live-2zBpCg/report.json`：最终补充隔离回归，包含取消瞬间原生对端推理仍活动的断言。

| --- | --- | --- |

也没有对已输出推理进行自动重放。

## 首字与流式耗时

以下为主回归中单次请求的观测值，单位毫秒。准备时间及原生首输出阶段来自
`Server-Timing`；客户端首字从发起请求到收到首个非空文本增量计时。
“冷”仅表示新的 OpenCode 进程，并非清空操作系统或模型服务缓存。

| 模式 | 准备阶段 | 原生首输出阶段 | 客户端首字 |
| --- | ---: | ---: | ---: |
| 独立进程，冷启动 | 2122 | 2432 | 4559 |
| 独立进程，复用 | 129 | 2218 | 2350 |
| 共享进程，冷启动 | 2170 | 2242 | 4416 |
| 共享进程，复用 | 451 | 1792 | 2246 |
| 共享进程，预热后首请求 | 127 | 2905 | 3036 |
| 共享进程，后续复用 1 | 165 | 2012 | 2180 |
| 共享进程，后续复用 2 | 151 | 1310 | 1465 |

独立计时的预热耗时为 **2359 ms**，没有计入“预热后首请求”。预热后的三个请求均返回
`x-opencode-worker-reused=true`。这证实预热/复用路径生效，准备阶段避免了本次约 2.2 秒
的进程初始化；真实模型等待时间波动明显，不能据这些少量样本承诺固定百分比的首字提升。

20 行中文/Emoji 测试的流式观测：

| 协议 | 首字 | 总耗时 | 非空文本增量数 | 最后输出至终止事件 |
| --- | ---: | ---: | ---: | ---: |
| Chat | 2998 | 4125 | 359 | 0 |
| Responses | 3425 | 4678 | 399 | 86 |
| Anthropic | 2144 | 3504 | 419 | 0 |

全部在完整回复生成前就收到了文本，未出现 UTF-8 替换字符。这里的增量数是协议事件数，
不等同于模型 token 数。

## 测试请求修正及边界

最初探索脚本把 Anthropic 系统提示放在 `messages` 中，代理正确返回 400。
修正为协议要求的顶层 `system` 后，三轮对话通过；没有放宽产品输入校验。
另一组提示用含糊的“secret”询问历史，Flash 返回拒绝或声称没有该值。
最终测试改用明确的非敏感测试标签，同时校验原始消息仍在展开历史中，历史续接与异常后恢复均通过。
本轮未据这些提示差异修改产品逻辑。

共享进程退出会影响同组正在运行的请求；本记录的进程退出场景验证单个被中断请求和后续恢复，
不承诺让崩溃时的其他活动请求继续完成。未测试真实供应商宕机、限额、OAuth 刷新、长时间稳定性
或实际外部工具副作用；工具结果由测试客户端生成并回传。此前模拟供应商的持续并发内存结果
属于另一项测量，本记录没有将其描述为真实模型内存压测。

## 复测

```powershell
npm run test:live:shared
```

该命令固定只允许 `deepseek-flash`，并要求其在当前配置中启用且支持工具。
无需设置真实网关 Key，也不修改正在使用的网关。可选定向执行：

```powershell
$env:OPENCODE_PROXY_LIVE_FILTER='native-event-disconnect-after-first-text|parallel-cancel-preserves-peer|concurrent-same-tool-name'
npm run test:live:shared
```

连通性检查始终执行。报告写入新建系统临时目录；真实模型测试不加入 CI。
代码入口为 `scripts/live-shared.mjs`，协议解析和计时共用 `scripts/live-client.mjs`。
新增回归脚本后的 `npm test`：**158 通过，0 失败**；脚本语法检查及 `git diff --check` 通过。
